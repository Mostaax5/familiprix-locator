Point de départ du scan
Choisissez ici le vrai point de départ du scan. La vue sert seulement à savoir de quel bout de l'allée vous la regardez, pour inverser le Côté A et le Côté B correctement. Le menu « Slot exact » permet de choisir directement n'importe quelle position valide.
Chemin de scan
Ordre du scan dans chaque allée: Façade A → Côté A (sections/tablettes/accroches) → Côté B → Façade B. Les présentoirs sont accessibles séparément depuis le scan, hors de ce chemin séquentiel.

Importez le PDF de planogramme Familiprix. Choisissez l’allée, le côté et la section de départ — les produits sont insérés tablette par tablette, position par position, dans l’ordre du planogramme.

Catalogue — tous les planogrammes
Importez le fichier plano_catalog.json (généré à partir de tous vos PDF). Cela enregistre tous les produits dans la base, même ceux pas encore placés. Seules les descriptions et images vérifiées pour l’UPC exact sont reliées aux produits placés; l’import d’un PDF ajoute leur emplacement. N’affecte pas le placement.
Les descriptions et images sont enrichies automatiquement en arrière-plan à partir du code Familiprix et de l’UPC exact. Les sources générales restent à confirmer et ne remplacent jamais une donnée plus fiable.
⬇ Liste des produits sans description (CSV)
Lorsqu’aucune source exacte ne répond immédiatement, une description provisoire est construite uniquement avec les champs déjà reliés au même UPC. Elle reste marquée « à confirmer » pendant que les sources fiables continuent d’être recherchées.
