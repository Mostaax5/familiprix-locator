Point de départ du scan
Choisissez ici le vrai point de départ du scan. La vue sert seulement à savoir de quel bout de l'allée vous la regardez, pour inverser le Côté A et le Côté B correctement. Le menu « Slot exact » permet de choisir directement n'importe quelle position valide.
Chemin de scan
Ordre du scan dans chaque allée: Façade A → Côté A (sections/tablettes/accroches) → Côté B → Façade B. Les présentoirs sont accessibles séparément depuis le scan, hors de ce chemin séquentiel.
Importer un planogramme PDF
Importez le PDF de planogramme Familiprix. Choisissez l’allée, le côté et la section de départ — les produits sont insérés tablette par tablette, position par position, dans l’ordre du planogramme.
Catalogue — tous les planogrammes
Importez le fichier plano_catalog.json (généré à partir de tous vos PDF). Cela enregistre tous les produits dans la base — même ceux pas encore placés, pour que la recherche par code-barres trouve leur nom — et complète le code pharmacie et les façades des produits déjà placés. N’affecte pas le placement.
Optionnel : aller chercher en ligne les vraies descriptions et images pour les produits du catalogue. Chaque résultat est vérifié contre le nom Familiprix (jamais le mauvais produit). Ça tourne en arrière-plan et peut prendre un moment — gardez cette page ouverte.
⬇ Liste des produits sans description (CSV)
Les produits que l’enrichissement ne peut pas décrire de façon fiable sont marqués (statut « aucune correspondance ») — cette liste vous permet de leur donner la bonne description plus tard.
